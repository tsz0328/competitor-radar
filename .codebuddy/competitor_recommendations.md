# 竞品雷达 · 推荐添加竞品清单（跨行业 + AI 合并版 · 2026-09）

> 项目定位已确认：**「竞品雷达」是通用竞品监控 SaaS，不限 AI 产品**，监控任意同类 SaaS / App 的官网、定价页、更新日志、博客、状态页、应用商店页，靠快照 Diff + LLM 解读出情报。
> 所以下面这份清单是**跨行业的真实候选 + AI 产品专项**——挑那些「公开页面齐全、更新频繁、Diff 信号强」的产品。AI 只是众多行业之一，但单列出来方便你批量加。

---

## 一、我们在挑什么样的「竞品」

雷达的监控对象是「**一个你持续关注的产品**」，下面挂若干**数据源**（homepage / pricing / changelog / blog / docs / status / rss / app_store）。

选品三条标准：
1. **公开页面齐全**：至少 homepage + changelog + status 三件套，Diff 才有料。
2. **更新频繁**：情报密度高（否则雷达天天空转）。
3. **跨行业**：证明工具不挑赛道——协作、设计、开发云、支付、知识库、电商 SaaS、AI 都行。

国内外都给（工具对任何公开页面都能抓）。

## 四、落地到雷达里的建议

1. **先建「跨行业首批 8 个」（2.1）+「AI 产品首批 8 个」（2.2）**，共 16 个，跨 9+ 个行业，演示 + 自用都好看且有情报价值。
2. **每个竞品建议挂的数据源**（以 Notion 为例，可套用）：
   - `homepage` → `https://www.notion.so/`（每天）
   - `pricing` → `https://www.notion.so/pricing`（每天）
   - `changelog` → `https://www.notion.so/releases`（每天）
   - `blog` → `https://www.notion.so/blog`（每天/RSS）
   - `status` → `https://status.notion.so/`（每小时）
3. **AI 产品的数据源差异**（重要）：
   - 国产大模型（豆包/元宝/Kimi 等）**通常没有独立 changelog 页**，主要盯 `homepage`（新模型 banner）+ `blog` + `pricing`（会员/API 价）。
   - AI 编程助手（Cursor/Claude Code/Trae/Copilot）**changelog 规范**，优先挂 `changelog` + `pricing`。
   - Agent 平台里 **Dify 是开源的**，可额外挂 `github_releases`（langgenius/dify）作为强信号源。
4. **值得盯的信号类型**（对应雷达的事件分类）：
   - 功能更新（changelog 新增条目 / 首页 banner 新模型）
   - 价格变化（pricing 文案/数字变动，AI 产品尤其爱调 API 单价）
   - 内容更新（blog 新文章、docs 改动）
   - 服务异动（status 故障/维护）
   - 舆论动态（blog 表态、重大合作、开源发布）
